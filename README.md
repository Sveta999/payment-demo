# Демо анимаций оплаты картой

Одна самодостаточная страница (`index.html`, видео и картинки внутри) с двумя вкладками:

- **Дизайн карт** — выбор карты на дуге, протяжка вниз, фон меняется на дизайн карты, терминал «проявляется» в дизайне карты.
- **Исчезающая сумма** — сумма растворяется в вихрь на телефоне и собирается из частиц на терминале.

Открыть локально: просто откройте `index.html` в браузере.

Публикация через GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
